Position is derived, and it is stable. Height is each node's longest-path depth through the prerequisite graph, so the layout is identical on every load — unlike a force layout, where position is emergent and means nothing on its own.

Colour and shape are the type, together: identity is the pair, so it still reads without colour vision. Size is degree.

Select a node and the lattice re-lights by personalized PageRank seeded on it — importance relative to where you are standing, not global importance. Everything it cannot reach goes grey.

The graph is Alpha Centauri's technology tree, as Neural Amplifier stores it in Quipu.
